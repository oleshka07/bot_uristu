# Коуч по цілях — Cloudflare Worker

Телеграм-бот, який щодня тисне на одну ціль, пише прогрес у твою Google
Таблицю і показує той самий шаблон окремою сторінкою. Живе повністю в хмарі
Cloudflare — ноутбук не потрібен.

Це **окремий сервіс**. Він не залежить від Python-застосунку в цьому ж репозиторії
і не деплоїться разом із ним: свій рантайм, свій деплой (`npx wrangler deploy`),
своє сховище (сама таблиця + KV для памʼяті).

## Що вміє

| Коли (київський час) | Що робить |
|---|---|
| щодня 16:00 | питає про **одну** активну ціль |
| щодня 22:00 | якщо не відповів — колюче нагадування (один раз) |
| субота 09:00 | тижневе саммері: цифри Pers/Work/разом, зміни статусів проти минулої суботи, по яких цілях були записи; тиждень без руху називається злитим |
| у відповідь на твоє повідомлення | Claude розбирає відповідь і сам викликає `save_progress` / `set_status` |

Команди в чаті: `/ask`, `/status`, `/week`, `/site`, `/help`.

Сторінка з таблицею: `GET /dashboard?t=<DASHBOARD_TOKEN>` — три дашборди
(Pers, Work, Pers and Work) і список цілей за пріоритетом з останнім записом коуча.

## Формат таблиці

Колонки: `A` горизонт · `B` пріоритет 10–100 · `C` тип (`Pers`/`Work`) ·
`D` текст цілі · `E` відповідальний · `F` відповідальний #2 · `G` статус ·
`H` нотатки бота.

Статуси: `not started`, `in progress`, `almost`, `done`, `cancelled`,
`postponed to next year`, `postponed to far future`.
Активні для бота — перші три.

Шапка шукається динамічно (рядок, де колонка A починається з «На що впливає»),
тому вставка рядків зверху нічого не ламає. Рядок без тексту цілі в `D`
ціллю не вважається — підвал зі списком ресурсів відсіюється сам.

Порядок питань: спершу цілі, яких бот ще не торкався; далі — найдавніше
торкані (за останньою датою в `H`); за рівності — вищий пріоритет.
Вчорашня відповіджена ціль сьогодні не питається.

## Розгортання

```bash
cd coach-worker
npm test                       # 17 тестів логіки та наскрізного сценарію
npx wrangler login
```

**1. KV для памʼяті бота**

```bash
npx wrangler kv namespace create COACH_KV
```
Виданий `id` вписати у `wrangler.toml` замість `REPLACE_WITH_KV_NAMESPACE_ID`.

**2. Змінні у `wrangler.toml`** (не секрети, їх можна комітити):
`SHEET_ID` (з URL таблиці), `SHEET_TAB` (назва вкладки; порожньо = перша),
`ALLOWED_CHAT_ID`.

Свій `chat_id`: напиши боту будь-що і відкрий
`https://api.telegram.org/bot<TOKEN>/getUpdates` — це до реєстрації вебхука.

**3. Сервісний акаунт Google**

У Google Cloud: увімкнути **Google Sheets API**, створити service account,
завантажити JSON-ключ. Далі **розшарити таблицю на його `client_email`
з правами Editor** — без цього бот побачить 403.

**4. Секрети** (тільки так, ніколи не в файлах і не в чатах):

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put GOOGLE_SA_JSON      # вставити весь JSON цілком
npx wrangler secret put WEBHOOK_SECRET      # openssl rand -hex 24
npx wrangler secret put DASHBOARD_TOKEN     # openssl rand -hex 24
```

**5. Деплой і вебхук**

```bash
npx wrangler deploy
curl -X POST "https://<твій-воркер>.workers.dev/admin/set-webhook?t=<DASHBOARD_TOKEN>"
```

Перевірка: `/health` віддає `ok`, у чаті `/status` показує цифри,
`/site` присилає посилання на сторінку.

## Рішення, які варто знати

- **Крон щогодини, а не тричі на добу.** Cloudflare рахує крон у UTC і не знає
  про переведення годинника. Воркер прокидається щогодини й сам питає
  `Intl` про київський час — розклад не їде ні влітку, ні взимку.
- **Ціль шукається за текстом, а не за номером рядка.** Вставиш рядок між
  питанням і відповіддю — запис усе одно ляже в правильну ціль.
- **Запис у таблицю через `valueInputOption: RAW`**, щоб Sheets не перетворив
  нотатку «06.09.26: ...» на дату.
- **Статус від моделі валідується** проти списку з семи — вигаданий статус
  у таблицю не потрапить.
- **Чужі чати ігноруються мовчки**, вебхук перевіряє
  `X-Telegram-Bot-Api-Secret-Token`, сторінка — токен у query.
- **Параметр `effort`** шлеться в Claude API; якщо конкретна модель його не
  приймає, воркер один раз це помічає і далі шле запити без нього.

## Ліміти

- KV має затримку реплікації; для одного власника й одного питання на день це
  не грає ролі, але два `/ask` в одну секунду можуть дати два питання.
- Сторінка читає таблицю на кожен запит (без кешу) — це свіжо, але не для
  публічного трафіку. Токен нікому не давати.
